# Chaos Simulator · 混沌模拟器

Chaos Simulator runs six extreme societal disruptions — internet shutdown, AI takeover, global blackout, currency collapse, infinite abundance, memory deletion — through three social configurations (high-trust liberal democracy, high-capacity authoritarian state, weak-state federation) and returns honest first-90-days plus first-year arcs. The honest middle, not the doomsday vignette. Bilingual (EN / 中文), dark/light, custom brand (Big Shoulders Display 700 + Manrope body + JetBrains Mono on `#0a0814` with chaos-orange `#ff6f3c` plus collapse-crimson, blackout-shadow, abundance-emerald, memory-violet, ai-cyan, money-gold, internet-amber codes; Noto Sans SC for Chinese). Hero: animated SVG fractured-grid with offset-by-distance disruption pattern. Four modules: C1 Six Disruptions (6 cards × honest description, click-to-load), C2 The Simulator (6 × 3 = 18 templated multi-section futures with first-90-days and year-long arc), C3 Chaos Reader (5 multi-paragraph canned probes — collapse-fantasy critique, best-case analysis, how-to-prepare honestly, memory-disruption defense, human-nature-under-disruption — plus free-text heuristic), C4 Guardrails (explicit refusal of collapse pornography, prepper fantasy, utopian abundance, real-event prediction, infinite-AI-generation slop). The simulator deliberately tracks the boring administrative middle that the genre skips.
